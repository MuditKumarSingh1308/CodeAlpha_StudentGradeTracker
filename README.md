# Student Grade Tracker

A console-based Java application that manages student records and calculates academic performance.

## Features

- Add student records.
- Prevent duplicate student IDs.
- Display all registered students.
- Calculate average marks.
- Find highest and lowest marks.
- Generate a student summary report.
- Validate user input, including IDs, names and marks.

## Technologies Used

- Java
- Object-Oriented Programming (OOP)
- ArrayList and List
- Java Collections Framework
- Exception Handling
- Scanner for user input

## How to Run

1. Clone or download this repository.
2. Open the project in a Java-compatible IDE.
3. Run `Main.java`.
4. Follow the console menu to manage student records.
